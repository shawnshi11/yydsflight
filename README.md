## ❓ 常见问题（FAQ）

<details>
<summary><b>VPN、机场、翻墙、科学上网，这几个词有什么区别？</b></summary>

本质上是同一类工具：通过**代理服务器（节点）**中转流量，实现访问境外网络资源。「机场」是圈内对「付费节点订阅服务」的俗称——你订阅后拿到一个订阅地址，客户端自动拉取一批**节点**，按延迟/倍率自行选择连接。YYDS Flight 就是一个**机场**，提供的就是这套**节点订阅 + 客户端导入**的完整体验。

</details>

<details>
<summary><b>连不上 / 很慢怎么办？</b></summary>

先在客户端里「更新订阅」，然后换一个延迟更低的节点；仍不行请在官网控制台提交工单或联系客服，附上客户端截图。

</details>

<details>
<summary><b>支持几台设备同时在线？</b></summary>

以你购买的套餐为准，控制台可随时查看已用/剩余流量与设备数。订阅地址绑定账号，**请勿分享**，否则会触发设备数限制。

</details>

<details>
<summary><b>流量是怎么计算的？</b></summary>

按实际使用量统计（上行 + 下行合计），部分高速节点标注了倍率，按倍率折算。控制台实时可见。

</details>

<details>
<summary><b>可以续费吗？兑换码怎么用？</b></summary>

可以，控制台订阅卡片点「续费」即可，时长自动叠加；兑换码在控制台「兑换码」处激活。

</details>

## 🛠️ 技术栈（本站开源组件）

YYDS Flight 官网与面板基于以下技术构建：

- **[Halo](https://github.com/halo-dev/halo)** — 现代开源建站平台（面板/内容）

- **Caddy** — 反向代理与 TLS
- **Cloudflare** — DNS / 边缘
